  2. Le modèle est nettoyé à l'import : sommets en double, faces cassées, normales, mise à l'échelle.

    Moins de faces : plus léger pour le web et les jeux. Plus de faces : plus de détails. Ré-importer refait le squelette et les animations.

  3. Hanches, colonne, tête, bras et jambes sont placés d'après la forme du personnage, puis le maillage est lié aux os.

  4. Animations à créer

  5. L'export GLB crée aussi une page web prête à mettre en ligne.

      Routeur de décision

      Avant un geste coûteux ou risqué (réessayer après une erreur, exécuter du code, relancer une génération, refaire une étape), l'app demande à un petit modèle de choisir : continuer, réutiliser l'existant, arrêter de réessayer, limiter l'effort ou te demander.

      Observation : le routeur donne son avis, l'app le note sans changer de comportement, et le rapport compare. Passe en actif quand ses avis te conviennent.

      Le SDK de Jev n'est pas installé : relance ./install.sh, ou pip install typesafe-sdk.
